# Описание проекта

Этот проект содержит код для автономного искусственного интеллекта-агента.

## Основные возможности:
- Управление системой
- Работа с файлами
- Выполнение математических операций
- Взаимодействие с пользователем

## Структура проекта:
- gigachat_v3.1(1).py — основной файл с кодом ИИ-агента

## Инструкции по запуску:
1. Установите необходимые зависимости
2. Запустите файл gigachat_v3.1(1).py
