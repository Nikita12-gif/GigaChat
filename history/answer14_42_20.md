### Шаги для создания сайта:

1. Создание структуры проекта
2. Написание HTML-кода для страниц
3. Добавление стилей с использованием CSS

### 1. Создание структуры проекта
Создадим простую структуру сайта с тремя основными страницами: главная страница, страница о нас и контактная информация.

```bash
mkdir my-site
cd my-site
```

Теперь создадим три основных страницы:

```bash
touch index.html
touch about-us.html
touch contact-us.html
```

### 2. Написание HTML-кода для страниц

Открой файл `index.html` и вставь следующий код:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Главная страница</title>
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <header>
        <h1>Добро пожаловать!</h1>
    </header>
    
    <main>
        <p>Это главная страница нашего сайта.</p>
    </main>

    <footer>
        <p>&copy; 2023 Наш сайт</p>
    </footer>
</body>
</html>
```

Теперь открой файл `about-us.html` и вставь аналогичный код:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>О нас</title>
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <header>
        <h1>О нас</h1>
    </header>
    
    <main>
        <p>Здесь мы расскажем немного о себе.</p>
    </main>

    <footer>
        <p>&copy; 2023 Наш сайт</p>
    </footer>
</body>
</html>
```

И наконец, создай файл `contact-us.html` с аналогичным содержанием.

### 3. Добавление стилей с использованием CSS

Создай файл `styles.css` и добавь базовые стили:

```css
/* styles.css */
body {
    font-family: Arial, sans-serif;
}

header, footer {
    background-color: #f4f4f4;
    padding: 10px;
    text-align: center;
}

main {
    padding: 20px;
}
```

### Итоговая структура проекта:

```
my-site/
│
├── index.html
├── about-us.html
└── contact-us.html
│
└── styles.css
```

### Запуск сайта

Чтобы посмотреть твой сайт, просто открой файл `index.html` в браузере. Ты можешь добавлять больше контента, разделять страницы на секции и улучшать дизайн с помощью CSS.

Если тебе интересно углубиться дальше, можем обсудить использование JavaScript или перейти к созданию динамического сайта на фреймворке типа React или Django!
