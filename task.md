# Задание: Разработка интеллектуального HR-агента для подбора сотрудников

## Цель проекта
Создать интеллектуального агента для руководителя компании, который анализирует базу сотрудников и рекомендует 2-3 наиболее подходящих кандидата для выполнения конкретной задачи.

## Задачи проекта


### 1. Разработать агента на Python
Агент должен уметь:
- Загружать данные из CSV файла data.csv
- Принимать от пользователя описание задачи
- Анализировать всех сотрудников с помощью GigaChat
- Выдавать 2-3 лучших кандидата с обоснованием выбора

### 3. Реализовать интерфейс взаимодействия
Интерфейс должен включать:
- Консольный ввод задачи
- Вывод рекомендаций в читаемом формате
- Возможность множественных запросов
- Команду exit для выхода из программы

## Требования к реализации

### Технические требования:
- Python 3.8+
- Библиотеки: gigachat, python-dotenv
- API ключ GigaChat в файле .env
- Чтение данных из data.csv с разделителем ";"

### Функциональные требования:
- Агент должен анализировать соответствие навыков, опыта и качеств сотрудников задаче
- Для каждого кандидата указывать конкретные причины выбора
- Оценивать соответствие в процентах
- Учитывать личные предпочтения сотрудников

## Критерии оценки
- Корректность подбора кандидатов
- Качество обоснования выбора
- Устойчивость к ошибкам (некорректный ввод, проблемы с файлом)
- Читаемость кода и наличие комментариев

## Дополнительные рекомендации
- Используйте системный промпт для настройки роли GigaChat как HR-аналитика
- Форматируйте данные о сотрудниках в удобный для анализа текстовый формат
- Обрабатывайте возможные ошибки при чтении файла и работе с API
- Добавьте информативные сообщения для пользователя о ходе выполнения программы
